3 Bước đơn giản để nạp: 3 Simple Steps: 書き込み手順: 简易烧录步骤:
1
Nối chân IO0 vào GND rồi cắm cáp USB. Bridge IO0 to GND, then plug USB in. IO0 を GND に接続し、USBを挿す。 短接 IO0 与 GND，然后插入 USB 线。
2
Nhấn nút "Cài Đặt" ở trên → Chọn cổng USB COM. Click "Install" above → Select your USB COM Port. 上の 「インストール」 をクリック → COMポート選択。 点击上方 “立即安装” → 选择串口端口。
3
Nạp xong: Rút dây IO0 ra và nhấn nút RST để chạy! Finished: Disconnect IO0 and press RST! 完了後: IO0 を抜いて RST ボタンを押す！ 完成后：拔掉 IO0 短接线 并按 RST 启动！
