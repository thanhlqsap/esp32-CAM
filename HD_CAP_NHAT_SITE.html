📖 HỆ THỐNG CẬP NHẬT TỰ ĐỘNG BẰNG JSON

Hướng Dẫn Cập Nhật Version & Changelog Dễ Dàng

Không cần sửa code HTML! Trang web tự động tải danh sách phiên bản, link nạp firmware và toàn bộ Changelog từ 2 file JSON.

📁 1. Hai File JSON Cần Chỉnh Sửa Khi Có Phiên Bản Mới

Tên File Vị Trí Lưu Mục Đích & Cơ Chế Hoạt Động
docs/changelog.json docs/changelog.json Dành cho trang Web Installer (GitHub Pages): Tự động tạo menu chọn version, cập nhật mô tả tóm tắt và hiển thị toàn bộ cửa sổ lịch sử Changelog trên trang web nạp.
version.json Thư mục gốc /version.json Dành cho ESP32 Cloud Auto-OTA: ESP32-CAM đọc file này qua Wi-Fi để biết có phiên bản mới cần cập nhật không (khi người dùng bấm Kiểm tra trong Tab 3 Dashboard).

📜 2. Cách Cập Nhật `docs/changelog.json`

Mỗi khi có bản nâng cấp mới, bạn chỉ cần chèn thêm 1 mục JSON lên đầu danh sách trong file docs/changelog.json:

💡
Lợi ích: Bạn hoàn toàn không cần chạm vào file HTML! Trang web docs/index.html sẽ tự động đọc file này và cập nhật giao diện ngay khi tải trang.

☁️ 3. Cách Cập Nhật `version.json` (Cho Cloud Auto-OTA)

Mở file version.json ở thư mục gốc và đổi số version: 

{
  "version": "1.0.1",
  "url": "https://raw.githubusercontent.com/<your-username>/ESP32_cam/main/build/OTA.bin",
  "notes": "v1.0.1: Tối ưu bộ nhớ đệm và tăng tốc độ Live Stream"
}

⚡ 4. Quy Trình 4 Bước Đơn Giản Mỗi Khi Có Code Mới

  1. Biên dịch xuất Firmware mới:

    Click đúp build_firmware.bat để tạo file build/OTA.bin mới nhất.

  2. Cập nhật version.json:

    Sửa lại số phiên bản mới (ví dụ: 1.0.1).

  3. Thêm 1 mục vào docs/changelog.json:

    Ghi chú các điểm mới trong bản này (tiếng Việt hoặc đa ngôn ngữ).

  4. Đẩy lên GitHub:

    Chạy lệnh: git add . → git commit -m "Release v1.0.1" → git push origin main.
